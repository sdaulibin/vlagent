# VLAgent 智能文档识别平台

## 项目概述

VLAgent 是一个基于 AI 大模型的智能文档信息提取与比对平台，面向审计、会计等金融行业场景，提供从文档上传、智能识别、结构化提取到差异比对的端到端解决方案。

平台采用前后端分离架构，后端基于 **Python FastAPI**，前端基于 **Vue 3 + TypeScript**，AI 能力由 **通义千问（Qwen3.5-122B）** 视觉语言模型驱动。

## 核心能力

### 7 大功能模块

| 模块 | 说明 |
|---|---|
| **流水识别** | 上传银行流水 PDF，自动识别银行类型，提取交易明细、账户信息和汇总统计，支持导出 Excel |
| **询证函识别** | 上传银行询证函，AI 提取 13 个关键字段（编号、事务所、联系方式、银行信息、印章日期等） |
| **文档比对** | 上传两份文档（PDF/Word），逐页对齐并做字符级差异标注，支持嵌套表格提取和章节结构化比对 |
| **询证函格式比对** | 上传询证函与标准模板比对，AI 识别格式类型并逐项检查节次、表头差异 |
| **发票识别** | 上传发票 PDF/图片，自动提取发票类型、号码、日期、金额、购销方等信息 |
| **类凭证识别** | 支持 8 种凭证类型智能识别，详见下文 |
| **通用 PDF 提取** | 用户自定义提取字段，AI 从任意 PDF 中提取结构化信息，支持 JSON/CSV/XLSX 导出 |

### 类凭证识别模块

支持 **8 种** 银行业务凭证类型的 AI 结构化信息提取：

| 凭证类型 | 提取内容 | 特殊处理 |
|---|---|---|
| **身份证** | 正反面检测、姓名、性别、民族、出生日期、住址、证件号码、签发机关、有效期 | — |
| **电子印章** | 文件类型、印章编码（支持多枚印章） | 图片自动切片、倒立检测与旋转、逐字符核验、旋转图片二次提取 |
| **银行卡** | 卡号、剪角检测 | — |
| **电子凭证** | 付款人/收款人、账号、金额、交易日期、流水号、手写签字检测 | — |
| **网银申请书** | 企业信息、法人/经办人信息、关联账户、操作户信息、审核方式 | 关联账户以表格展示（企业网银/手机银行 × 查询/转账）、操作户信息表格展示（渠道/录入/审核/管理/其他权限） |
| **违法告知书** | 账号、手印检测 | — |
| **开户申请书** | 30+ 字段全面提取（存款人信息、法人信息、财务负责人、账户性质、银行处理记录等） | 字段类型约束、罕见字识别（如"灝"）、数字区分（2 vs 6）、底部文字完整提取 |
| **授权委托书** | 委托人/被授权人信息、15 项授权事项（开户类/变更类/注销类）的勾选状态 | 手写 √/× 符号识别、类别边界方框防错配、后处理一致性校验 |

## 技术亮点

### 文档处理

- **多银行支持**：内置 11 家银行的识别策略（工行、农行、中行、建行、交行、招行、光大、广发、邮储、济宁、山东地方银行），采用策略模式可扩展
- **字符级精确比对**：基于 Google diff-match-patch 的字符级差异算法，配合动态规划实现不等页数的自动对齐
- **嵌套表格提取**：递归提取 DOCX 中的嵌套表格内容，确保结构化数据不丢失
- **章节结构化比对**：文档按标题层级拆分为结构化章节，支持章节级别的差异比对和定位

### AI 识别增强

- **手写符号识别**：通过精细的 Prompt 工程引导模型区分手写 √（对号）和 ×（叉号），包含 COT 强制识别流程
- **类别边界防错**：针对授权委托书等表单中类别边界处方框易错配的问题，加入边界专项提醒和后处理一致性校验
- **字符混淆纠正**：针对印章编码、日期等字段，加入 E/6/B/5、P/F、G/6/C、2/6 等易混淆字符的逐字符区分规则
- **旋转印章处理**：电子印章编码提取时，对每个切片 tile 做 180° 旋转重新提取，取最优结果
- **幻觉检测与修正**：AI 识别结果经多层后处理（正则校验、交叉验证、频次分析、白名单过滤），降低幻觉输出

### 系统架构

- **异步任务处理**：文档比对、凭证识别等耗时操作采用 FastAPI BackgroundTask 后台处理，前端轮询获取状态
- **实时状态轮询**：所有异步处理模块（凭证识别、发票识别、询证函、格式比对等）均实现前端轮询机制，任务完成后自动刷新结果
- **多格式输入**：支持 PDF、DOCX、DOC、JPG、PNG 等多种文件格式
- **嵌入式部署**：支持 iframe 嵌入，通过 URL 参数 / sessionStorage / postMessage 多种方式获取认证令牌

## 部署架构

- **容器化部署**：Docker + Kubernetes（Helm Charts），前后端独立容器
- **反向代理**：前端通过 Nginx/OpenResty 反向代理 `/api` 至后端服务
- **SunECM 集成**：JPype 桥接 Java SDK，对接文档管理平台
- **嵌入式部署**：支持 iframe 场景，通过 postMessage 获取认证令牌
- **CI/CD**：Jenkins 多环境流水线（SIT / UAT / PRD）
